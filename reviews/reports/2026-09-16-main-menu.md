## Summary

nginx-config **claims** a numbered TTY list (case 3: empty argv owned by zero-arguments; installed+TTY overlays onto `app_main_menu`; `menu` / `main` are the same handler). Membership, Exit **9**, off-TTY no-hang, and do-not-capture-read are correct. The list is still a **one-shot dispatcher**: a valid pick runs the verb and **leaves the program**, invalid picks use `[WARN]` not `[ERROR]`, short names are unstyled, and root-required `Next:` from the list names `menu` (or a wrong default verb) instead of `apply` / `remove-lpu`. Product default-interaction law (2026-09-13) has not absorbed harness 1.17.0 / 1.18.0 (hierarchy table, invalid-choice `out_error`, command-finished front board).

**Verdict: Revise** — do not Pass while after-leaf exit and wrong `Next:` remain.

## Issues

### Issue 1 -- Severity: bug
- File: nginx-config:3067
- Description: After a valid numbered or typed leaf, `app_main_menu` restores flags, unsets `INTERACTIVE`, runs `app_run_command`, and `return $?`. PTY pick **2** listed profiles and the process ended. Harness term **command-finished-front-board** (and a typed leaf on the front board) requires reprinting the front board. Product REQ does not yet name that rule; the live UX is still a one-shot menu.
- Suggestion: After a successful leaf, loop back to `app_menu_print` (keep the `while`). Treat only front **9** / `exit` / `quit` as leave. Add **TP-CLI-18** (product id for front-after-leaf).
- Lesson: L-MENU-LEAF-EXIT
- Test: TP-CLI-18
- Status: open

### Issue 2 -- Severity: bug
- File: nginx-config:2378
- Description: `check_root` interpolates `${COMMAND:-nginx-conf}`. From `nginx-config menu` pick **4**, live stderr was `Next: sudo nginx-config menu`. From installed empty-argv the token is empty → `Next: sudo nginx-config nginx-conf`. Operator cannot run that to apply. 2026-09-06 already flagged weak root `Next:` copy.
- Suggestion: Pass the leaf verb into `check_root` (or set `COMMAND` to the chosen verb before `app_run_command`). Expect `Next: sudo nginx-config apply`.
- Lesson: L-MENU-NEXT
- Test: TP-CLI-19 companion or TP-NGINX-CONFIG-09 PTY-from-menu
- Status: open
